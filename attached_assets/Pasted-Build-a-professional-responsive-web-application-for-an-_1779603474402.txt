EA MARKETPLACE

Create a professional EA marketplace.

Features:

- List all available EAs
- EA categories
- Search and filter
- EA performance analytics
- Backtest reports
- Subscription pricing
- Download section
- User reviews and ratings
- License management system

Each EA purchase should:

- Generate encrypted EX5 file
- Lock EA to specific MT5 account number
- Lock EA to broker server
- Prevent usage on other MT5 accounts
- Have subscription expiry
- Validate online license
- Disable automatically after expiry

EA Purchase Workflow:

1. User subscribes
2. User enters MT5 account number and broker server
3. Payment successful
4. License generated
5. Encrypted EX5 file generated
6. User downloads locked EX5 file
