Build a professional responsive web application for an Investment & Trading Services Platform that works perfectly on desktop, laptop, tablet, and mobile devices.

Technology Stack:

- Frontend: Next.js + React + Tailwind CSS + TypeScript
- Backend: Node.js + Express/NestJS
- Database: PostgreSQL
- Authentication: JWT + OTP + 2FA
- File Uploads: Secure cloud storage
- Admin UI: Modern analytics dashboard
- Deployment Ready
- Dark/Light mode
- Fully responsive UI

Application Name:
“Kuber Quant”

Main Modules:

1. Investment Platform
2. Algo Trading Subscription
3. Copy Trading Services
4. Account Handling Services
5. EA Marketplace
6. Referral System
7. KYC Verification System
8. Fiat & Crypto Deposit/Withdrawal System

==================================================
USER ROLES & HIERARCHY

1. Super Admin

- Full platform control
- Manage website logo, banners, content, pages, FAQs
- Manage investment plans
- Manage payment gateways
- Manage crypto wallet addresses
- Manage UPI IDs and QR codes
- Manage users and managers
- Manage referrals and commissions
- Manage ROI settings
- Approve/reject deposits and withdrawals
- Approve/reject KYC
- Manage EA subscriptions
- Generate reports
- View all analytics
- Configure profit sharing
- Configure subscription plans
- Configure lock system for EAs

2. Managers

- Manage assigned investors
- Review KYC
- Review deposit proofs
- Review withdrawal requests
- View reports
- Handle support tickets
- Managers can also invest as users

3. Users / Investors

- Register/login
- Complete KYC verification
- Invest in plans
- Deposit and withdraw funds
- Subscribe to EA services
- Subscribe to copy trading
- Submit MT5 credentials for account handling
- View analytics and ROI
- Manage bank and crypto withdrawal details
- Upload transaction proof
- Download purchased EA files
