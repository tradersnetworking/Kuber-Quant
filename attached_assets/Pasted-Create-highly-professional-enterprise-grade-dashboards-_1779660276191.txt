Create highly professional, enterprise-grade dashboards for an Investment, Algo Trading, Copy Trading, and EA Subscription Platform.

The dashboards must have:

- Premium fintech UI/UX
- Responsive layouts for desktop/tablet/mobile
- Modern cards, analytics, charts, tables
- Dark/light mode
- Real-time updates
- Advanced filtering and search
- Export reports (PDF/Excel/CSV)
- Notifications system
- Role-based permissions
- Fast loading performance
- Secure session management
- Sidebar + top navigation layout
- Collapsible menus
- Animated statistics and charts
- Professional typography and spacing

Use:

- Next.js
- React
- Tailwind CSS
- TypeScript
- Framer Motion
- Recharts
- PostgreSQL
- Node.js backend APIs
